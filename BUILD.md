# Building HexedVoiceMod

The build instructions now live in the README: see **[README.md - Building on GitHub / Building locally](README.md#building-on-github)**.

In short: push the project to GitHub, open the *Actions* tab, run `build-hexedvoicemod` and download the `HexedVoiceMod` artifact (`libHexedVoiceMod.so`). The workflow downloads RubberBand and RNNoise itself.
